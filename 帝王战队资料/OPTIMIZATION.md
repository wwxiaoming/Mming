## 九、全部 key / secondary_keys 优化方向

**指令**：「所有世界书的 key 优化一下」

### 优化原则

1. key 保持中文、简洁、无标点
2. secondary_keys 控制在 3-7 个，删除低频/弱关联词
3. 英雄条目的 key = 英雄名，secondary_keys = 代号 + 系别 + 核心特征（2-3 个）
4. 装置条目的 secondary_keys 必须包含对应英雄名（确保触发）

### 示例修正
