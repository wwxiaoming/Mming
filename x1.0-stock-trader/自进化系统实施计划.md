### 3.2 `backtest_tracker.py` — 选股后表现追踪

**输入**: 过去 N 天的 `daily_picks.json`
**处理**:
1. 遍历每个交易日的 9 大策略选股记录
2. 对每只股票,拉取选股日之后的日 K 线
3. 以**次日开盘价**为基准(T+1 制度),计算 T+1/T+3/T+5/T+10/T+20 收益率
4. 记录区间最高/最低收益

**输出**: `tracking_YYYYMMDD.json`
```json
[{
  "date": "2026-06-20",
  "strategy": "1_momentum",
  "code": "300665",
  "name": "飞鹿股份",
  "price_at_pick": 11.76,
  "base_price": 11.80,  // 次日开盘
  "returns": {"T+1": 2.1, "T+3": 5.3, "T+5": -1.2, "T+10": 8.5, "T+20": 3.2},
  "max_return": 12.5,
  "min_return": -3.8
}]
```

### 3.3 `multi_dimension_analysis.py` — 7 维度分析

| 维度 | 函数 | 分析内容 |
|------|------|---------|
| dim1 策略 | `analyze_by_strategy()` | 9 策略各自的命中率/收益/盈亏比 |
| dim2 板块 | `analyze_by_sector()` | 按 reason 关键词归类板块表现 |
| dim3 时间窗口 | `analyze_by_timeframe()` | T+1~T+20 最佳持有周期 |
| dim4 市值 | `analyze_by_mcap()` | 5 档市值区间表现 |
| dim5 美股 | `analyze_us_market_impact()` | 美股隔夜信号 vs A 股实际表现 |
| dim6 评分 | `analyze_by_score()` | 五引擎评分分位 vs 实际收益 |
| dim7 错误 | `analyze_errors()` | 亏损标的共性分析 |

### 3.4 `strategy_evaluator.py` — 策略评级

评级标准:
- ⭐⭐⭐ 优秀: 命中率 > 60% 且超额收益 > 2%
- ⭐⭐ 合格: 命中率 50-60% 或超额收益 0-2%
- ⭐ 不及格: 命中率 < 50% 或超额收益 < 0%

输出: 每个策略的评级 + 动作建议(保持/加大/降低/暂停)

### 3.5 `weight_optimizer.py` — 权重优化

x1.0 当前五引擎权重: 位置 0.20 / 估值 0.15 / 资金 0.30 / 题材 0.20 / 美股 0.15

优化逻辑:
1. 按策略有效性计算综合评分(命中率 0.4 + 收益 0.4 + 盈亏比 0.2)
2. 表现好的加权,差的减权,每次调整幅度 ≤ 30%(防过拟合)
3. 归一化保持总和 = 1.0
4. 输出新旧权重对比 + 调整理由

### 3.6 `report_generator.py` — 报告生成

输出 Markdown 报告,7 大章节:
1. 执行摘要(命中率/平均收益/超额收益/最佳/最差)
2. 策略有效性分析(9 策略评级表)
3. 最佳持有周期(T+1~T+20)
4. 评分体系有效性(高分是否优于低分)
5. 错误分析(TOP 10 亏损标的)
6. 权重优化建议(新旧对比)
7. 行动建议(自动生成的改进措施)

### 3.7 `run_all.py` — 一键执行

```bash
python3 scripts/evolution/run_all.py --days=30
```

流程: backtest_tracker → multi_dimension_analysis → strategy_evaluator → weight_optimizer → report_generator

## 四、技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| K 线数据源 | 腾讯财经 API | 不封 IP,与现有 `_common.py` 一致 |
| 收益基准 | 次日开盘价 | T+1 制度,选股当日无法买入 |
| 样本要求 | ≥ 30 天 | 文档第七章要求,样本太少不具统计意义 |
| 权重调整幅度 | ≤ 30% | 防过拟合(文档第七章) |
| 停牌处理 | 跳过不计入 | 文档第七章 |
| 沪深 300 基准 | 实时拉取 | 计算超额收益 |
