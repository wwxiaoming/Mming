# longbridge-value-investing

## 中文简介

价值投资分析，运用格雷厄姆（NCAV/净流动资产/防御型投资者）和巴菲特（经济护城河/ROE/FCF）方法论。覆盖个股诊断和批量筛选，支持双方法论（Graham 烟蒂股 + Buffett 优质复利）。运行前先做跨报表对账再评分。数据源优先 Longbridge CLI，MCP 兜底，WebSearch 仅补缺。

## 所属层级

L2 选股

## 触发词

格雷厄姆、巴菲特、捡烟蒂、烟蒂股、NCAV、净流动资产、护城河、价值投资、安全边际、深度价值、防御型投资者

## 核心能力

- 唯一同时覆盖 Graham（NCAV 烟蒂）+ Buffett（经济护城河）双方法论
- 跨报表对账、防御型投资者打分、优质复利打分
- 数据源优先 Longbridge CLI → MCP 兜底 → WebSearch 补缺
