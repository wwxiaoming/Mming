# market-breadth-analyzer

## 中文简介

用 TraderMonty 公开 CSV 数据量化市场广度健康度。生成 0-100 综合分（100=健康），6 个分项组成，无需 API key。当用户询问市场广度、参与率、涨跌家数健康度、行情是否普涨，或一般市场健康评估时使用。

## 所属层级

附录 A1（美股/跨市场工具，仅作港美股联动参考）

## 触发词

市场广度、涨跌家数、参与率、普涨、市场健康

## 核心能力

- 用 TraderMonty 公开 CSV 数据量化市场广度健康度
- 生成 0-100 综合分（100=健康），6 个分项组成
- 仅在美股大盘预检用，不直接套用到 A 股广度判断
