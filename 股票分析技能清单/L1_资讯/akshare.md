# akshare

## 中文简介

通过 AkShare 库获取中文金融数据。提供 A 股、港股、美股、期货、基金的实时与历史数据，及宏观经济指标。当用户请求中国市场数据、股价、市场分析或中国交易所金融信息时使用。支持股票行情、历史数据、期货行情、基金信息、宏观指标、实时市场动态。

## 所属层级

L1 资讯

## 触发词

A股数据、港股数据、期货数据、宏观数据、金融数据、AkShare

## 核心能力

- 全 pandas DataFrame 返回、零 API key、即装即用
- 覆盖 A 股 / 港股 / 美股 / 期货 / 基金的实时与历史数据
- 叠加 GDP / CPI / PMI 宏观经济指标
- 支持前/后复权与多周期
