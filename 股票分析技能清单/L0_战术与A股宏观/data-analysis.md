# data-analysis

## 中文简介

本地 Excel/CSV 数据分析工具。处理用户自有的财务数据包，支持多 sheet、聚合、过滤、SQL 查询、透视表、可视化，可对 L0/L1 数据二次加工。支持 CSV/JSON/Markdown 多格式导出。

## 所属层级

L0 战术与 A 股宏观（v2.1 自 L3 升级）

## 触发词

数据分析、Excel、CSV、透视表、SQL查询、数据导出

## 核心能力

- 处理用户自有的财务数据包（多 sheet、聚合、过滤、SQL 查询、导出）
- 透视表 + SQL + CSV/JSON/Markdown 导出 + 可视化
- 可对 L0/L1 数据二次加工
- 把 L0 工具的输出 CSV 拼接为综合仪表板
